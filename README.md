# ScreenTimeTracker
Python script to log and analyze daily screen time via Windows CMD.
Log hours, view reports, get feedback message, and visualize trends with a bar chart.
This is a CLI tool — simple, lightweight, and easy to use.

**Technologies Used**
1. Python 3.x – main programming language
2. JSON – for storing daily screen time data (data.json)
3. Matplotlib – for bar chart visualization

**Features**
Log daily screen time with your most-used app.
View total and average screen time.
Receive feedback message based on usage.
Bar chart visualization to track trends over time.
Data automatically stored in data.json.

**Requirements**
Python 3.x – required to run the script
Matplotlib – optional, only needed if you want the bar chart feature.
